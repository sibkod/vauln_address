About This Project

Wallet Checker is a security tool designed to help you verify if a wallet address has been compromised. We maintain a database of 1,000 wallets with three status levels.

300 Hacked
300 Vulnerable
400 Safe

Features

  • ✅ Check any Ethereum wallet against our hacked database
  • 🔐 Connect your wallet via MetaMask for unlimited checks
  • 🔄 Live alerts showing checks from the community in real-time
  • 🛡️ One free check without wallet connection
  • ⚠️ Vulnerable status — wallet not yet hacked, but all data needed for compromise is available
  • ⚡ Instant results with clear visual feedback

⚠️ Disclaimer: This tool is for educational and security awareness purposes only. Always verify information through multiple sources before making security decisions.
